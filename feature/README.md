# Feature Subsystem

## Overview
Presentation and user experience layer for KReader, encapsulating book library management and reader viewports.

## Subdirectories & Boundaries
- `library`: [./library/README.md](./library/README.md) - Book grid UI, vault onboarding, metadata extraction, search filtering, and book file sharing.
- `reader`: [./reader/README.md](./reader/README.md) - EPUB reading screen, Readium navigator hosting, floating overlays, typography controls, and annotation sheets.
